右侧设定供应商，写一段提示词。可拖入参考图做图生图，
生成的每个结果都会落在画布上，随手拖动、缩放、继续编辑。

空格+拖拽 平移 滚轮 缩放 Ctrl+V 粘贴图片 Delete 删除选中
Pictorium 图片生成
未配置供应商
点击右上角 ⚙ 进行设置
参考图 可选
＋ 拖入 / 点击 / 从画布选
带参考图时会走「图生图 / 编辑」；提示词里可写“保持人物不变，改成…”
对话会保存在本机。可以问“帮我优化这条提示词”。

供应商设置

图片模型（当前）
可从下方列表点击选择；也可以手输任意模型名。

数据与隐私

供应商信息存在浏览器。所有 API 请求由本地 server.js 中转（为了绕过 CORS），服务端只负责转发，不写盘、不落日志。

操作速查

空格 / 中键拖拽 / 空白处拖拽平移画布
滚轮以光标为中心缩放
Ctrl = / - / 0放大 / 缩小 / 复位
F适应全部内容
拖拽卡片移动图片 / 拖动四角缩放手柄
Ctrl+V / 拖入文件作为参考图，或直接落图到画布
双击卡片把该图设为参考图
Delete删除选中卡片
Enter / Shift+Enter发送 / 换行
