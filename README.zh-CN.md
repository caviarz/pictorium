# Pictorium

**无限画布上的 GPT-Image** —— 自托管的 AI 图片生成工作台。

自己填供应商信息，输入提示词生成图片，可选参考图，所有产出都摊在一张可平移、可缩放的画布上。
支持文生图、图生图、批量出图与动图 GIF。

> **关键词：** GPT-Image · gpt-image-1 · AI 画图 · 文生图 · 图生图 · 无限画布 ·
> 图片编辑器 · OpenAI 兼容 · 自托管 · 动图 GIF · 零依赖

开箱即用 GPT-Image，也能接任何 OpenAI 兼容端点。

没有安装步骤，没有构建步骤，不依赖任何框架。**运行时零依赖** —— 有 Node.js 和浏览器就能跑。

## 功能

- **自带供应商** —— 任何 OpenAI 兼容端点。Base URL、API Key、鉴权方式、模型名、附加请求头都在界面里填。
  代码里没有任何硬编码配置。
- **无限画布** —— 平移、缩放、框选、拖动、缩放卡片、多选，位置全部持久化。
- **文生图 / 图生图** —— 参考图数量不限。
- **动图 GIF** —— 字节级识别，原始字节无损保存，可播放可暂停，下载扩展名正确。
- **对话模式** —— 流式响应，含 `reasoning_content`（思考过程）的单独处理。
- **本地持久化** —— 图片字节存 IndexedDB，元数据存 localStorage。
  除了你自己的供应商，不向任何地方发送数据。
- **健壮** —— 生成慢时有分阶段进度；失败会保留提示词并可重试；
  本地数据损坏时优雅降级，而不是白屏。

## 快速开始

```bash
git clone https://github.com/caviarz/pictorium.git
cd pictorium
node server.js
```

打开 **http://127.0.0.1:8787** —— 首次运行会自动弹出设置面板。

Windows 上也可以直接双击 `start.bat`。

**环境要求：** Node.js 18+（用到内置 `fetch`）。运行应用本身不需要 `npm install`。

## 配置供应商

点右上角 **⚙**。所有配置只存在你浏览器的 localStorage 里，不上传任何服务器。

| 字段 | 说明 |
|---|---|
| **Base URL** | OpenAI 兼容地址，填到 `/v1`；不带会自动补上。 |
| **API Key** | 你的密钥，仅存本机。 |
| **鉴权方式** | `bearer`（`Authorization: Bearer …`）/ `x-api-key` / 两者 / 不带（本地 Ollama 用「不带」）。 |
| **图片模型** | 如 `gpt-image-1`。点「拉取模型」从 `/models` 获取，也可手输任意模型名。 |
| **对话模型** | 可选。留空则复用图片模型（多数图片模型不支持对话）。 |
| **附加请求头** | 可选 JSON，给需要额外头的网关用。 |

内置三个预设：OpenAI 官方、通用兼容、本地 Ollama。
保存前建议先点 **测试连通性**。

程序会自动拼出 `/models`、`/chat/completions`、`/images/generations`、`/images/edits` 四个端点。

## 生成图片

**文生图** —— 输入提示词，按 **生成**（`Enter` 发送，`Shift+Enter` 换行）。
结果落在画布上，带提示词和真实像素尺寸。

**图生图** —— 加一张或多张参考图（拖进参考图栏，或 hover 卡片点 **＋**）。
有参考图时会走 `/images/edits`。

**参数**

| 参数 | 取值 |
|---|---|
| 尺寸 | `auto`、`1024x1024`、`1536x1024`、`1024x1536` |
| 质量 | `auto` / `low` / `medium` / `high` |
| 格式 | `png` / `jpeg` / `webp` |
| 张数 | 1–4 张，一排铺开 |
| 按参考图比例 | 自动选最接近参考图比例的尺寸 |

### 动图（GIF）

**要拿到真正的动图，尺寸必须设 `auto`。** 这是实测结论，不是推测：

| 尺寸参数 | 结果 |
|---|---|
| `auto` 或不传 | **GIF 动图**，通常 10–18 帧 |
| `1024x1024` | **静态 PNG**，零动帧 |

固定尺寸会把输出锁死在单张画布上，模型只能返回静帧；`auto` 才允许它自由决定画布尺寸和帧数。

应用会检测提示词里的动图相关词（`GIF`、`动图`、`animated`、`帧`、`looping` …）并自动切到 `auto`。
可以在参数区用「要动图时自动用 auto 尺寸」关掉这个行为。

动图在整条链路上如何被保住：

| 环节 | 做法 |
|---|---|
| **识别** | 字节魔数（`GIF`、`RIFF..WEBP`、PNG `acTL`）。**不信任** `blob.type` 和 data URL 前缀。 |
| **归一化** | 动图**永不**经过 canvas 缩放 —— canvas 只能取第一帧，等于把动画毁掉。 |
| **存储** | 原始字节进 IndexedDB；元数据记录 `animated` / `frames` / `format`。 |
| **恢复** | 从元数据读回标记；旧记录按字节重新嗅探补齐。 |
| **显示** | `动图 · N 帧` 徽标带脉冲点；点徽标或双击图片可暂停。 |
| **下载** | 扩展名按真实字节判定。 |
| **复制** | 以 `image/gif` 写剪贴板；不支持时降级为首帧 PNG 并明确提示。 |

### 生成过程中的反馈

一张图常要 40–120 秒，界面会尽量让你知道它还在干活：

- **分阶段进度** —— `正在连接… → 已提交，等待模型响应… → 模型正在绘制… → 仍在生成…`。
  进度条最多走到 95%，不会假装完成；超过 90 秒会提示可以取消。
- **空状态立刻消失** —— 点下生成的一瞬间就换成占位卡。
- **失败保留提示词** —— 失败或取消的卡片留在画布上并写明原因，
  点 **↻ 重试** 用原提示词在原位置重新生成。失败卡不会被持久化。
- **合理落点** —— 新卡片一定完整落在可视区内且互相错开。
  视口实在装不下时按阶梯错开，每张都留可点击的边缘，而不是被推出屏幕或叠在一个像素上。
- **缩小也能点中** —— 卡片按钮有扩展命中区，50% 缩放下依然好用。

## 数据与隐私

除了请求你配置的供应商，数据不出本机。

| 内容 | 存放位置 |
|---|---|
| API Key、Base URL、模型名 | `localStorage`（`aic.provider.v1`） |
| 卡片元数据（位置、尺寸、提示词） | `localStorage`（`aic.cards.v1`） |
| 图片字节 | IndexedDB 数据库 `ai-canvas`（沿用项目旧名，这样已有图片不会丢） |
| 对话历史、界面状态、视口 | `localStorage` |

图片**先**写入 IndexedDB，**再**写引用它的元数据，所以刷新绝不会出现元数据指向丢失的字节。
IndexedDB 失败时回退到内联 data URL，并在空间紧张时给出提示。

要清空全部数据，在浏览器里清除 `127.0.0.1:8787` 的站点数据即可。

## 实现说明

应用是三个普通 ES 模块加一个小服务端，没有打包器。

**为什么需要本地服务端？** 浏览器因 CORS 无法直连大多数图片 API，
供应商通常也会拒绝缺少其来源的请求。`server.js` 负责代理并归一化各种供应商的返回格式。

- **图生图降级链** —— 依次尝试 JSON `images: [dataURL]`、multipart `image[]`、
  multipart `image`、最后退到纯生成。不同网关接受不同形状，程序自动找到能用的那种。
- **参考图走临时文件** —— 大参考图先上传到临时目录，避免请求体过大。
- **SSE 透传** —— 思考内容和正文分开推送；忽略 `stream: true` 的供应商也能处理。
- **长超时** —— 15 分钟，动图和大图不会被提前掐断。

```

├─ test-robustness.js   # 13 项损坏数据测试（无需 API Key）
├─ run-regression.js    # 16 项界面/持久化回归（无需 API Key）

```

## 测试

不需要外部 API 的测试：

```bash
npm install                 # 仅浏览器测试需要（playwright-core）
npm test                    # 跑下面三套（约 2 分钟）
# 或者单独跑：
```


## 安全说明

这是一个**本地优先的开发者工具**，不是加固过的公共服务。

- 服务端默认只绑定 `127.0.0.1`，请保持这样。
- `/api/*` 设置了 `Access-Control-Allow-Origin: *`，方便你在别的端口开发前端。
  但它与 `HOST=0.0.0.0` 组合时，**任何网站都能调用你的本地 API 并消耗你的额度**。
  如需对外暴露，请自行加鉴权。
- API Key 以明文存在浏览器 localStorage。本地工具常见做法，
  但在共用电脑上不要这么做。
- 静态文件服务已拒绝路径穿越，但这个服务端不适合直接面向公网。

几条约定：

- `public/app.js` 是单个 IIFE，刻意保持零依赖。
- 新卡片落点必须始终保持在可视区内 —— 有测试盯着这条。
- 动图绝不能经过 canvas 渲染。
- 所有读 localStorage 的地方要能容忍类型错误，而不只是非法 JSON。
